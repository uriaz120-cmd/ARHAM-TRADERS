Normalize Stored Weights (0.5 → 500)

This tool will:

  • Create a browser-localStorage backup of the app stores.
  • Multiply numeric weight fields by 1000 in these stores: bookings, warehouse, production, finished_goods, deliveries.
  • Leave other fields untouched.

Warning: This modifies data in your browser only. Open this page in the same browser/profile where you use the app.

If you're ready, click Convert (0.5 → 500). A backup key will be created like at_backup_<timestamp>.
